# m-football-notes

这是一个用于归档和发布多个独立 HTML 页面的仓库。  
内容主要围绕足球相关的笔记、记录与参考资料，以静态页面形式呈现。

## 项目简介

本仓库不针对任何特定网站或域名，仅作为个人或协作项目中与足球相关的 HTML 页面存档与展示用途。  
所有页面均为独立文件，可直接通过浏览器打开查看。

## 目录结构

仓库根目录下存放 HTML 文件及其他资源文件，结构如下：

```
m-football-notes/
├── index.html          # 页面索引（可选）
├── page1.html          # 示例页面
├── page2.html          # 示例页面
└── assets/             # 静态资源（图片、样式、脚本等）
```

- `index.html` 为可选的入口页面，用于列出仓库中的其他页面链接。  
- 每个 HTML 页面均独立完整，不依赖外部服务。

## 页面归档说明

- 所有页面内容均与足球相关，包括但不限于比赛记录、数据分析、战术笔记、术语整理等。  
- 页面采用纯前端技术（HTML + CSS + JavaScript），无后端依赖。  
- 不包含任何商业推广、诱导点击或外部链接跳转。
